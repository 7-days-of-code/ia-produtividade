# 🤖 Dia 7 · Assistente Pessoal de Produtividade

O Mega-Prompt final, juntando os 6 blocos anteriores em camadas:

```
# 1. CONTEXTO SOBRE MIM     → Perfil do Dia 1
# 2. TRIAGEM                → regras do Dia 2
# 3. RESUMOS                → formato do Dia 3
# 4. PRIORIZAÇÃO            → critérios do Dia 4
# 5. MODELOS DE TEXTO       → exemplos do Dia 5
# 6. ANÁLISE DE DADOS       → regras do Dia 6
# 7. INSTRUÇÃO GERAL        → usar a seção certa conforme o pedido
```

**Como usar:** salve como instrução de sistema de um Projeto/GPT (ou cole no início de uma conversa nova) e peça direto: "triagem destes e-mails", "resuma esta reunião", "monta meu plano de hoje". Atualize só a seção 1 quando sua rotina mudar.
