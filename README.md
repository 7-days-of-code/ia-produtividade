# 🧩 Dia 5 · Modelos reutilizáveis

Prompt (exemplo, Few-Shot):

```
Dois exemplos de como eu escrevo um status report semanal:

EXEMPLO 1: STATUS: Semana 12-16/08 · Destaques: meta de cliques superada
em 12%. Riscos: orçamento em 90% de uso. Próximos passos: revisar criativos.

EXEMPLO 2: STATUS: Semana 19-23/08 · Destaques: nova parceria fechada.
Riscos: atraso na aprovação jurídica. Próximos passos: cobrar o jurídico.

AGORA: [contexto da semana atual]
```

**Saída esperada:** um terceiro status report, no mesmo formato e extensão dos dois exemplos. O mesmo prompt serve para follow-up e proposta, só trocando os exemplos de entrada.
